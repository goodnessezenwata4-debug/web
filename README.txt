WHAT WAS ADDED
--------------
1. All HTML is in index.html.
2. All styling is in style.css.
3. All JavaScript is in script.js.
4. Home / Services / About / Work / Contact stay in ONE HTML page.
5. Clicking navigation switches the visible full-screen section.
6. Main background uses the first image.
7. Service cards use your supplied images.
8. Work cards use your supplied images.
9. Preloader:
   - preloaded
   - preloaded hide
   - loader logo
   - loader line
   - loading percentage
10. Custom cursor:
   - cursor
   - cursor follower
   - cursor grow
11. Arrow Left / Arrow Right can switch sections.
12. Normal mouse-wheel section navigation is intentionally disabled.
